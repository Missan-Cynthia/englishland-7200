# 英文學習樂園 MVP

這是獨立英文版專案，不會讀寫「認字樂園 V3」。請以本機 HTTP 伺服器開啟（不可直接雙擊 `index.html`）：

```powershell
python -m http.server 8000
```

再開啟 `http://localhost:8000`。預設以瀏覽器 `localStorage` 依帳號保存。若要啟用雲端，請建立**全新的英文版 Firebase 專案**，將 Web 設定填入 `js/firebase-config.js`；程式會拒絕國字版 `elementary-chinese` 專案，且英文資料只寫入 `englishUsers` 集合。

## 全 App 錯題本與今日考題

首頁可進入共用錯題本及今日考題。一般單字、片語、閱讀、克漏字與思維導圖小測驗的錯誤統一保存至帳號狀態的 `study.cards`。單字、片語依英文合併，文章及克漏字依篇收錄並逐題追蹤；保留原文、四個選項、各題型最近一次錯誤與累計次數。支援待複習、常錯題、已熟練、四類篩選及搜尋。看解析不計熟練度；主動複習或今日考題跨三個不同日期答對才算熟練，同一天重做不重複計算，任何再次答錯都歸零。建議複習日會依進度延後，仍可隨時主動練習。

今日考題每日固定 8 次作答：單字 3 題、片語 2 題、短文理解 1 題、同一篇克漏字 2 題，預估 3–5 分鐘而非硬性限時。當地日期換日後產生新回合，每類依最近最多 30 次作答獨立調整；不足 8 次資料先使用入門範圍，正確率至少 80% 開放較高層級及片語克漏字，55%–79% 為中間層級。優先安排到期錯題，並保留已學／新題機會；已存在的單字與片語熟練度亦用於判斷已學內容。教材層級依現有資料，並非標準化能力測驗。每日題目、已答選項及成績隨帳號保存，可重新整理續答；已答題不重複發獎勵。

舊 `phraseMistakes` 會一次性匯入且保留錯誤次數；舊版沒有跨日作答紀錄，所以跨日熟練度從新制開始累積。其他未保存的歷史錯題不能回補。基礎閱讀、主題文章補入理解题；現有閱讀與克漏字题目補上中英選項、解釋及原文依據。進階單字原始資料未提供中文的項目仍只出聽音題，解析明確標示缺少釋義。

驗證：`node --test tests/*.test.mjs`；`node tests/study.browser.mjs` 使用隔離的 Edge 無頭測試環境與本機存取，不會登入正式 Firebase 帳號。可用 `PLAYWRIGHT_PACKAGE` 指定 Playwright 套件位置。

## 教材來源

- `data/phrases.json`：以使用者提供的 `data/新觀念狄克生片語_Unit1-30_課文與片語整理.docx` 為準，收錄 Unit 1–30 共 350 筆片語與中文釋義，取代舊 PDF 的 477 筆資料。`data/phrase-units.json` 保存全部 30 課原文，學習頁可展開閱讀。Word 沒有獨立英文釋義，因此不混入舊版英文解釋；例句只取自當課原文中直接包含片語的句子。新版使用獨立片語 ID，舊版熟練度不套用到新版項目。舊 PDF 與人工校對檔僅保留為歷史資料，不是目前 App 的片語來源。
- 重新匯入：`python scripts/import_phrase_docx.py "data/新觀念狄克生片語_Unit1-30_課文與片語整理.docx"`（需要 python-docx）。

- `data/basic.json`：由資料夾內 1200 PDF 擷取，共 1200 筆，含中文意思。
- `data/advanced.json`：由高中英文 7000 字 PDF 擷取，共 6035 個不重複詞項。來源只有英文與詞性，沒有中文翻譯，因此第一版先保留 `meaningPending`，進階區的「中文選英文」暫停啟用；聽音選英文可使用。
